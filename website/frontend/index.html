What should I expect from this slider?

At α = 0, Qwen still follows a neutral rewrite instruction. It may rephrase or remove profanity without steering. Compare different alpha values to explore the added intervention. Nearby values can produce identical text. Strong values can change meaning, reverse an action, or produce awkward wording.

This version exposes formality only. The finalized backend also supports a separate detoxification direction, which is set to zero here. The animated line is a schematic of the requested strength, not a measurement of the model’s hidden states.

BEHIND THE WORDING

A different intervention.
The same need for a careful read.

01 / A FIXED TASK

Start with a rewrite.

Qwen receives the same neutral instruction at every setting: rewrite the sentence while preserving its meaning. Moving the slider does not change that instruction.

02 / AN INTERNAL SHIFT

Add a learned direction.

A vector extracted from paired informal and formal GYAFC sentences is added to the output of decoder layer 11 during generation. Alpha controls its sign and size; the model weights stay unchanged.

03 / YOUR JUDGMENT

Choose what still means you.

More intervention does not always mean a better rewrite. Read the actual result, especially at stronger settings. The tool explores wording; it does not verify that every fact or intention survived.

THE EVERYDAY REWRITING PATH

There’s an extension, too.

The repository includes a Chrome extension with a separate local Python API and fine-tuned T5 rewriting models. It is another way to explore rephrasing, with a different inference pipeline from this page.

SEPARATE WORKFLOW

Local service, browser interface.

The current extension sends drafts to its local API. It does not run T5 inside the browser. Installation and model setup are documented in extension/README.md in the repository.

EVIDENCE BEFORE ASSURANCES

Reliability is something we measure.

The project includes evaluation tools for toxicity, formality, semantic similarity, and preservation of structured facts. These are diagnostic signals, not guarantees that an individual rewrite is correct.

RESEARCH IN PROGRESS

No score invented for your sentence.

This page shows real generated text and measured generation time. It does not compute a live formality, safety, or meaning-preservation score. Broader evaluation and experiment reports will be brought into the website in a later iteration.

ABOUT SECONDTHOUGHT

Room for a second thought.

We’re exploring ways to help people reconsider their wording while keeping what they mean. This first website connects our Qwen steering experiments to a writing interface. The browser extension explores a separate fine-tuned approach. The product direction will follow what we can demonstrate reliably.
