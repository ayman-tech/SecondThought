SET IT UP

Four steps, about five minutes.

The extension isn't in the Chrome Web Store yet, so you add it yourself. It's quick, and you only do it once.

  1. Download and unzip

    Unzip it somewhere it can stay, like Documents › SecondThought. Chrome runs the extension from that folder, so don't move or delete it later.

    Download the zip

  2. Add it to Chrome

    Open this address in a new tab:

    chrome://extensions

    Switch on Developer mode in the top-right corner, click Load unpacked, and choose the SecondThought folder you just unzipped.

  3. Start the rewriting service

    Rewrites happen on your own computer, so a small service needs to be running. In a terminal, from the project folder, run:

    uv run python -m extension.api.server

    Checking…

    First time on this computer?
    1. Install uv, which sets up Python for you.
    2. Get the project: git clone https://github.com/ayman-tech/SecondThought, then open that folder in a terminal.
    3. Install what it needs: uv sync --extra evaluation
    4. Put the both-t5 model folder in models/ (ask the team for it).

    The first start also downloads the tone-check models (about 500 MB). After that it starts in seconds.

  4. Pin it and try it

    Click the puzzle-piece icon in Chrome's toolbar and pin SecondThought. Then type something heated in Gmail or Slack. A small SecondThought? pill appears; click it for a calmer version you can drop in with one click.

Updating

Download the new zip, replace what's in your SecondThought folder, then click ↻ on SecondThought in chrome://extensions.

Pill not showing?

Refresh the page after installing. If the dot in the extension's popup is red, the service isn't running.

Your words stay yours

Nothing leaves the page until you click the pill, and then it only goes to the service on your own computer.
