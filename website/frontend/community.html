GET SECONDTHOUGHT

Set it up in three easy steps.

It's free, needs no admin password, and everything you write stays on your own computer.

  • A Windows or Mac computer
  • Chrome, Edge or Brave
  • About 4 GB of free space
  • Around 10 minutes
  1. 1

    Download and open the setup

    Download for Windows

    Not on Windows?

    Open the file you downloaded. A window opens and sets everything up on its own, including the writing model. Leave it running, it takes about 5 minutes.

    "Windows protected your PC"? That's normal for new apps. Click More info, then Run anyway.

    Open the file you downloaded to unzip it, then double-click SecondThought Setup. A window opens and sets everything up, including the writing model. Leave it running, it takes about 5 minutes.

    Mac won't open it? Go to System Settings → Privacy & Security, scroll down and click Open Anyway.

  2. 2

    Add it to your browser

    When the setup is done, it opens your browser's extensions page and a folder. On that page:

    1. Turn on Developer mode (top-right corner).
    2. Click Load unpacked.
    3. Pick the frontend folder that opened.

    You only have to do this once.

  3. 3

    Start it and try it

    Double-click Start SecondThought on your Desktop and leave its window open. Then type something heated in Gmail or Slack and click the SecondThought? bubble.

Questions

Is my writing private?

Yes. SecondThought only reads your text when you click the bubble, and even then it stays on your computer. Nothing is sent to us.

Why does my computer warn me about it?

We're a student project, so Microsoft and Apple haven't signed our setup file. You can see exactly what it does under "For developers" below.

Do I have to keep that window open?

Yes, while you want suggestions. That window is SecondThought working. Close it when you're done, and double-click Start SecondThought next time.

The bubble doesn't show up.

Refresh the page you're writing on. If the dot in the extension's menu is red, SecondThought isn't running. Double-click Start SecondThought on your Desktop.

The setup said it couldn't download the model.

Check your internet connection and open the setup again. It picks up where it left off. If it still fails, ask us for the both-t5 folder and put it in the models folder inside SecondThought (in your home folder).

How do I update?

Download and open the setup again, then click ↻ on SecondThought in your browser's extensions page.

How do I remove it?

Click Remove on SecondThought in your browser's extensions page. Then delete the SecondThought folder in your home folder and the shortcut on your Desktop.

For developers: terminal install, Linux and the manual zip

The setup file just runs one of these commands. You can paste it into a terminal instead:

irm {{ installer }}/install.ps1 | iex
curl -fsSL {{ installer }}/install.sh | sh
curl -fsSL {{ installer }}/install.sh | sh
  • It installs uv (which brings Python), clones the repo to ~/SecondThought, runs uv sync --extra evaluation, downloads the model from Hugging Face (or the release) and writes a start script. Read the scripts ↗
  • Already have the model? Set SECONDTHOUGHT_MODEL to the both-t5 folder or its zip before running, and the installer copies it in.
  • To install by hand, load the zip below with Load unpacked and run uv run python -m extension.api.server from the project.
