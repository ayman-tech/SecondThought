GET SECONDTHOUGHT

Up and running in three steps.

One command sets everything up on your computer. No admin rights needed, and nothing you write leaves your machine.

  • Windows, macOS or Linux
  • Chrome, Edge or Brave
  • About 4 GB free
  • No admin rights
  1. 1

    Run the installer

    Open PowerShell and paste:

    irm {{ installer }}/install.ps1 | iex

    Open Terminal and paste:

    curl -fsSL {{ installer }}/install.sh | sh

    Open a terminal and paste:

    curl -fsSL {{ installer }}/install.sh | sh

    About 5 minutes the first time. Run it again any time to update. View the script ↗

    What does it do?
    • Installs uv, which brings Python with it.
    • Downloads SecondThought into a SecondThought folder in your home folder.
    • Installs what it needs inside that folder only.
    • Creates a start script, then opens your browser's extensions page and the folder to add.
  2. 2

    Add it to your browser

    The installer opens your browser's extensions page and the SecondThought folder for you. Then:

    1. Switch on Developer mode in the top-right corner.
    2. Click Load unpacked.
    3. Choose the frontend folder it opened.

    Works in Chrome, Edge and Brave.

  3. 3

    Start it and try it

    Double-click start-secondthought in your SecondThought folder and keep its window open. Then type something heated in Gmail or Slack and click the SecondThought? pill.

    Checking…

One manual step for now. The rewriting model isn't public yet. Ask the team for the both-t5 folder and put it in SecondThought/models. Or point the installer at it first: $env:SECONDTHOUGHT_MODEL = "path\to\both-t5" on Windows, SECONDTHOUGHT_MODEL=path/to/both-t5 on macOS and Linux.

Questions

What do I need?

Windows, macOS or Linux, Chrome, Edge or Brave, and about 4 GB of free space. The first install needs an internet connection; after that, rewriting works offline.

Is my writing private?

Yes. Spotting happens inside the page, and your text only goes anywhere when you click the pill. Even then it goes to the service on your own computer, never to us.

How do I update?

Run the installer again, then click ↻ on SecondThought in your browser's extensions page.

How do I uninstall?

Click Remove on SecondThought in your browser's extensions page, then delete the SecondThought folder in your home folder.

Can I install it by hand instead?

Yes. Download the extension, unzip it somewhere it can stay, and load that folder with Load unpacked. You'll also need the project to run the service: uv run python -m extension.api.server from its folder.
